# Advent of Code 2024 solutions (C++)

I decided to learn C++ by completing all 50 [Advent of Code 2024](https://adventofcode.com/2024) challenges in a structured way, from a high-level framework to pseudocode to real code. I'm not going for elegance or efficiency here; if my code gets the job done without compiler warnings, that's good enough.

Pseudocode in this repo is written with reference to the [OCR A-Level Pseudocode Guide](https://www.ocr.org.uk/Images/260952-pseudocode-guide.pdf).
